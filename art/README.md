# Painted artwork

Everything in this folder is generated by `tools/paint_all.py` (procedural painting: fractal noise,
light/normal simulation, ~5,000 simulated hair strands, metaball liquid for the blood).
Re-run it to regenerate:

```bash
cd tools && python3 paint_all.py
```

Needs Python 3 with numpy, opencv-python and scipy. Files here are embedded into the plugin at build time.
You can also replace any file with hand-made art of the same name and size.
